# Изолированная проверка интерфейса

После `npm ci` выполнить `node tests/preview/server.cjs` и открыть http://127.0.0.1:3015.
После изменения компонентов: `node tests/preview/server.cjs --build`, затем обновить страницу.

Стенд использует настоящие BoardClient, AppNav и стили приложения с синтетическими записями из fixture.json. Next-навигация заменена локальными адаптерами. API доступен только на loopback; все запросы записи отклоняются. База данных и авторизация приложения не используются. Это проверка интерфейса, а не интеграционный тест сохранения задач.

Проверить:

- Ширины 390, 768, 1024, 1440 и 1920: нет горизонтального переполнения страницы и обрезанных карточек.
- Поиск, фильтр приоритета/исполнителя, сброс и счётчик активных фильтров.
- Закрытие фильтров по Escape и клику снаружи.
- Доска, список, таймлайн, «Моя работа».
- Открытие карточки и формы создания, закрытие без записи.
- Скрытие обеих панелей, перезагрузка и восстановление.
- Светлая и тёмная темы, мобильная навигация.
- Завершённые задачи с прошлой датой не показывают предупреждение «Скоро».

Регрессии сроков: `node --test tests/task-deadline.test.cjs`.
